# 회의실 예약 (예시) 기능 명세

> [!NOTE]
> 스킬과 파이프라인 확인용 예시 프로젝트의 기능 명세예요. 실제로 만들 서비스가 아니에요.

기능마다 **누가, 무엇을, 왜** 하는지와 **무엇이 되면 완성인지**를 적습니다. 화면을 만들고, 서버를 만들고, 코드 리뷰를 할 때 이 문서의 완료 조건으로 확인합니다.

- 기획서: [`spec.md`](spec.md)
- 이번 학기 기능만 적습니다 (`spec.md`의 `범위`에서 꼭 필요 / 있으면 좋음)

## F-01. 로그인

> **팀원**으로서 **출근부에서 쓰던 방법 그대로 로그인**하고 싶다. 그래야 **따로 가입하지 않아도 내 이름으로 예약할 수 있다**.

- 화면: 전체 (로그인 화면은 출근부와 같은 방식)
- 구분: 꼭 필요
- 관련 규칙: 예약하는 사람은 정보운영팀 팀원, 출근부·업무일지와 같은 로그인. 역할은 팀원 / 관리자

### 완료 조건

이 조건을 모두 확인할 수 있으면 완성입니다.

| #   | 상황 | 이렇게 하면 | 이렇게 된다 |
| --- | ---- | ----------- | ----------- |
| 1 | 로그인하지 않은 상태 | 앱을 열면 | 로그인 화면이 나오고, 출근부와 같은 방법으로 로그인할 수 있다 |
| 2 | 팀원이 | 로그인하면 | S-01 시간표가 보이고, '운영 규칙' 버튼은 보이지 않는다 |
| 3 | 관리자가 | 로그인하면 | S-01 시간표가 보이고, '운영 규칙' 버튼이 보인다 |
| 4 | 정보운영팀 팀원이 아닌 사람이 | 로그인하려고 하면 | "정보운영팀 팀원만 쓸 수 있어요" 안내가 나오고 들어갈 수 없다 |
| 5 | 한 번 로그인한 팀원이 | 다음 날 앱을 다시 열면 | 다시 로그인하지 않아도 시간표가 바로 보인다 |

### 확인 방법

- 팀원 계정으로 로그인 → S-01에 '운영 규칙' 버튼이 없는지 확인 → 로그아웃 → 관리자 계정으로 로그인 → '운영 규칙' 버튼이 있는지 확인

## F-02. 시간표 보기

> **팀원**으로서 **폰으로 하루 시간표를 보고 회의실이 언제 비었는지 확인**하고 싶다. 그래야 **회의실 앞까지 가 보지 않아도 빈 시간을 알 수 있다**.

- 화면: S-01
- 구분: 꼭 필요
- 관련 규칙: 회의실 1개, 30분 단위, 기본 평일 9~18시, 오늘부터 2주 앞까지, 지난 시간은 예약 불가

### 완료 조건

이 조건을 모두 확인할 수 있으면 완성입니다.

| #   | 상황 | 이렇게 하면 | 이렇게 된다 |
| --- | ---- | ----------- | ----------- |
| 1 | 오늘 10시~11시에 예약이 있는 날 | 앱을 열면 | 오늘 날짜 시간표가 9시~18시 30분 칸으로 보이고, 10시~11시는 한 덩어리로 예약한 사람과 회의 이름이 보인다 |
| 2 | 내가 잡은 예약이 있을 때 | 시간표를 보면 | 내 예약은 다른 사람 예약과 색이 다르다 |
| 3 | 오늘 오후 2시에 | 시간표를 보면 | 2시 전 칸은 흐리게 보이고 누를 수 없다 |
| 4 | 시간표에서 | 화살표를 누르거나 좌우로 밀면 | 다음 날·이전 날 시간표로 바뀌고, '오늘'을 누르면 오늘로 돌아온다 |
| 5 | 그날 예약이 하나도 없을 때 | 시간표를 보면 | 모든 칸이 비어 있고, 위에 "아직 예약이 없어요"가 보인다 |
| 6 | 토요일로 | 넘기면 | "예약할 수 없는 날이에요"가 보인다 (주말을 건너뛸지는 화면 단계에서 정함) |
| 7 | 오늘부터 2주 뒤 날짜에서 | 다음 날로 넘기려 하면 | 더 넘어가지 않는다 |

### 확인 방법

- 앱 열기 → 오늘 시간표와 지난 시간 확인 → 화살표로 다음 날, 주말, 2주 뒤까지 넘겨 보기 → '오늘' 누르기

## F-03. 예약하기

> **팀원**으로서 **빈 시간을 골라 회의실을 미리 예약**하고 싶다. 그래야 **다음 회의 때 회의실을 쓸 수 있을지 걱정하지 않아도 된다**.

- 화면: S-01, S-02
- 구분: 꼭 필요
- 관련 규칙: 30분 단위, 한 번에 최대 2시간, 누르는 즉시 확정, 이어진 빈 칸으로만 잡기, 예약 개수 제한 없음

### 완료 조건

이 조건을 모두 확인할 수 있으면 완성입니다.

| #   | 상황 | 이렇게 하면 | 이렇게 된다 |
| --- | ---- | ----------- | ----------- |
| 1 | 내일 2시~3시가 빈 날 | 2시 칸 → 2시 30분 칸을 누르면 | 2시~3시가 선택되고, 아래에 '이 시간 예약하기' 버튼이 뜬다 |
| 2 | 시간을 고른 뒤 | '이 시간 예약하기' → 회의 이름 "주간 회의" → '예약하기'를 누르면 | 바로 확정되고, 시간표의 2시~3시에 내 이름과 "주간 회의"가 보인다. 다른 팀원 폰에서도 보인다 |
| 3 | 예약하기 화면에서 | 회의 이름을 비워 두면 | '예약하기' 버튼이 눌리지 않는다 |
| 4 | 2시 칸을 고른 뒤 | 5시 칸(3시간)을 누르면 | "한 번에 최대 2시간까지 예약할 수 있어요" 안내가 나오고 선택되지 않는다 |
| 5 | 2시 칸을 고른 뒤 | 그 사이에 다른 예약이 있는 4시 칸을 누르면 | 선택되지 않는다 (예약된 칸을 넘어서 고를 수 없다) |
| 6 | 두 팀원이 같은 시간을 고른 상태에서 | 거의 동시에 '예약하기'를 누르면 | 먼저 누른 사람만 예약되고, 나중 사람에게는 "방금 다른 사람이 예약했어요" 안내 후 시간표로 돌아간다 |

### 확인 방법

- S-01에서 내일로 넘기기 → 2시, 2시 30분 칸 누르기 → '이 시간 예약하기' → "주간 회의" 적고 예약 → 시간표에 보이는지 확인
- 다른 계정 폰 두 대로 같은 시간을 동시에 예약해 보기

## F-04. 예약 상세 보기, 내 예약 취소

> **팀원**으로서 **안 쓰게 된 내 예약을 취소**하고 싶다. 그래야 **다른 팀원이 그 시간을 쓸 수 있다**.

- 화면: S-03
- 구분: 꼭 필요
- 관련 규칙: 팀원은 자기 예약만 취소, 이미 시작했거나 끝난 예약은 취소 불가, 예약은 고칠 수 없음

### 완료 조건

이 조건을 모두 확인할 수 있으면 완성입니다.

| #   | 상황 | 이렇게 하면 | 이렇게 된다 |
| --- | ---- | ----------- | ----------- |
| 1 | 내일 2시에 내 예약이 있을 때 | 시간표에서 그 예약을 누르면 | 예약 상세가 뜨고 회의 이름, 예약한 사람(나), 날짜·시간, '예약 취소' 버튼이 보인다 |
| 2 | 내 예약 상세에서 | '예약 취소' → 확인 팝업에서 '취소하기'를 누르면 | 시간표로 돌아가고 그 시간이 빈 칸이 된다 |
| 3 | 확인 팝업에서 | '닫기'를 누르면 | 아무것도 바뀌지 않는다 |
| 4 | 다른 팀원의 예약을 | 누르면 | 회의 이름, 예약한 사람, 날짜·시간만 보이고 '예약 취소' 버튼은 없다 |
| 5 | 지금 진행 중이거나 지난 내 예약을 | 누르면 | 내용은 보이지만 '예약 취소' 버튼이 없다 |

### 확인 방법

- 내일 예약 하나 만들기 → 눌러서 취소 → 빈 칸 확인
- 다른 계정의 예약을 눌러 버튼이 없는지 확인

## F-05. 관리자가 남의 예약 취소

> **관리자**로서 **문제가 있는 예약을 사유와 함께 취소**하고 싶다. 그래야 **예약 개수에 제한이 없어도 회의실을 공평하게 쓰게 할 수 있다**.

- 화면: S-03
- 구분: 꼭 필요
- 관련 규칙: 관리자는 모든 예약을 취소할 수 있다, 이미 시작했거나 끝난 예약은 취소 불가, 취소된 예약도 기록으로 남김 (상태: 관리자 취소)

### 완료 조건

이 조건을 모두 확인할 수 있으면 완성입니다.

| #   | 상황 | 이렇게 하면 | 이렇게 된다 |
| --- | ---- | ----------- | ----------- |
| 1 | 관리자가 다른 팀원의 예약을 | 누르면 | 예약 상세에 '예약 취소' 버튼이 보인다 |
| 2 | 관리자가 | '예약 취소' → 사유 "학교 행사" → '취소하기'를 누르면 | 시간표로 돌아가고 그 시간이 빈 칸이 된다. 예약한 팀원의 폰에서도 빈 칸으로 보인다 |
| 3 | 사유 입력 팝업에서 | 사유를 비워 두면 | '취소하기' 버튼이 눌리지 않는다 |
| 4 | 관리자가 | 자기 예약을 취소하면 | 팀원처럼 확인 팝업만 나오고 사유는 묻지 않는다 |
| 5 | 지금 진행 중이거나 지난 예약은 | 관리자가 눌러도 | '예약 취소' 버튼이 없다 |

### 확인 방법

- 팀원 계정으로 내일 예약 만들기 → 관리자 계정으로 그 예약 누르기 → 사유 적고 취소 → 팀원 계정에서 빈 칸 확인

## F-06. 관리자 취소 안내 메시지

> **팀원**으로서 **관리자가 내 예약을 취소했다는 걸 앱에서 바로 알고** 싶다. 그래야 **취소된 줄 모르고 회의실에 갔다가 헛걸음하지 않는다**.

- 화면: S-01
- 구분: 있으면 좋음 (여유가 생기면 가장 먼저)
- 관련 규칙: 폰 알림은 없다. 다음에 앱을 열 때 안내한다. 예약 상태 '관리자 취소'일 때만

### 완료 조건

이 조건을 모두 확인할 수 있으면 완성입니다.

| #   | 상황 | 이렇게 하면 | 이렇게 된다 |
| --- | ---- | ----------- | ----------- |
| 1 | 관리자가 내 예약을 취소한 뒤 | 앱을 열면 | 시간표 맨 위에 "관리자가 취소한 예약이 있어요 · 10/31(금) 14:00~15:00 · 사유: 학교 행사"가 보인다 |
| 2 | 안내가 보일 때 | '확인'을 누르면 | 안내가 사라지고, 앱을 다시 열어도 나오지 않는다 |
| 3 | 관리자가 내 예약 2개를 취소했을 때 | 앱을 열면 | 2개가 모두 안내에 보인다 (하나씩 띄울지 묶을지는 화면 단계에서 정함) |
| 4 | 내가 직접 취소한 예약은 | 앱을 열어도 | 안내가 나오지 않는다 |
| 5 | 관리자가 취소한 예약이 없으면 | 앱을 열어도 | 안내 자리가 비어 있고 시간표가 바로 보인다 |

### 확인 방법

- 팀원 계정으로 예약 → 관리자 계정으로 사유 적고 취소 → 팀원 계정으로 앱 다시 열기 → 안내 확인 → '확인' 누르고 다시 열어 사라졌는지 확인

## F-07. 시간 막기

> **관리자**로서 **청소나 행사가 있는 시간을 미리 막아** 두고 싶다. 그래야 **팀원이 쓸 수 없는 시간에 예약하는 일이 없다**.

- 화면: S-01, S-02, S-03
- 구분: 있으면 좋음
- 관련 규칙: 시간 막기는 관리자만, 겹친 예약은 함께 취소(막는 사유가 취소 사유), 막기를 풀어도 취소된 예약은 되살아나지 않음

### 완료 조건

이 조건을 모두 확인할 수 있으면 완성입니다.

| #   | 상황 | 이렇게 하면 | 이렇게 된다 |
| --- | ---- | ----------- | ----------- |
| 1 | 관리자가 빈 시간을 고르고 | 예약하기 화면에 들어가면 | 위쪽에 '예약 / 시간 막기' 탭이 보인다. 팀원에게는 이 탭이 없다 |
| 2 | '시간 막기' 탭에서 | 사유 "청소" → '시간 막기'를 누르면 | 시간표의 그 시간이 회색 '막힘 · 청소'로 바뀌고, 팀원은 그 칸을 고를 수 없다 |
| 3 | 막을 시간에 예약 2개가 있을 때 | '시간 막기'를 누르면 | "예약 2개가 함께 취소돼요" 확인 팝업이 뜬다. 확인하면 막힘으로 바뀌고 두 예약은 관리자 취소가 된다 (사유: 청소) |
| 4 | 그 확인 팝업에서 | '닫기'를 누르면 | 아무것도 바뀌지 않는다 |
| 5 | '시간 막기' 탭에서 | 사유를 비워 두면 | '시간 막기' 버튼이 눌리지 않는다 |
| 6 | 막힌 시간을 | 관리자가 누르면 | 사유와 '막기 풀기' 버튼이 보이고, 풀면 빈 칸이 된다. 막을 때 취소된 예약은 되살아나지 않는다 |

### 확인 방법

- 팀원 계정으로 내일 3시 예약 → 관리자 계정으로 2시~4시 고르기 → '시간 막기', 사유 "청소" → 팝업에서 확인 → 막힘과 팀원 쪽 취소 안내 확인 → 막힌 칸 눌러 풀기

## F-08. 운영 규칙 바꾸기

> **관리자**로서 **방학이나 학기에 맞게 예약 가능한 시간과 최대 길이를 직접 바꾸고** 싶다. 그래야 **바꿀 때마다 개발자에게 부탁하지 않아도 된다**.

- 화면: S-01, S-04
- 구분: 있으면 좋음
