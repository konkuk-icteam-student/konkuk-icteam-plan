# 장비 대여 관리

> 학생은 남은 장비를 보고 미리 예약하고, 근로학생은 창구에서 대여·반납을 버튼 하나로 기록하고, 관리자는 재고와 연체를 한눈에 보는 정보운영팀 장비 대여 서비스

## 배경

지금은 장비 대여를 엑셀·구글 시트에 근로학생이 직접 적어 관리한다. 기한이 지났는데 반납하지 않은 사람을 시트에서 눈으로 찾아 따로 연락해야 하고, 지금 빌려줄 수 있는 장비가 몇 개인지 바로 알 수 없다. 그래서 "노트북 남아 있어요?" 같은 학생 문의에 매번 확인해서 답해야 하고, 바쁠 때 기록을 빠뜨리거나 잘못 적어 실제 재고와 맞지 않는 일이 생긴다.

## 사용자

| 역할     | 누구인지             | 기기   | 이 서비스에서 하는 일          |
| -------- | -------------------- | ------ | ------------------------------ |
| 학생     | 장비를 빌리는 학생   | 모바일 | 남은 장비 확인, 미리 예약      |
| 근로학생 | 정보운영팀 근로학생  | 모바일 | 창구에서 대여·반납 처리        |
| 관리자   | 정보운영팀 담당 직원 | PC     | 장비 등록, 대여·연체 현황 확인 |

## 핵심 시나리오

사용자가 실제로 하는 일을 순서대로 적습니다. 화면 이름은 아래 화면 목록의 ID를 씁니다.

### S1. 장비 예약 (학생)

1. 학교 계정으로 로그인하면 S-01에서 장비 종류별 남은 수량과 내 대여 현황을 본다
2. 빌리고 싶은 장비 종류를 누른다 → S-02
3. 달력에서 받을 날과 반납일을 고른다. 그 장비의 최대 대여 기간보다 길게는 고를 수 없다
4. '예약하기' → 확인 팝업 → 예약 완료. S-01의 내 대여 현황에 예약이 생긴다

### S2. 예약한 장비 받기 (근로학생)

1. 학생이 창구에 오면 S-04의 '오늘 받을 예약' 탭에서 이름·학번으로 검색한다
2. 예약을 누른다 → S-05. 건넬 기기 번호(예: 노트북-03)를 고른다
3. '대여 완료' → 예약이 '대여 중'으로 바뀌고 반납일이 학생 화면에 보인다

### S3. 예약 없이 바로 빌리기 (근로학생)

1. S-04에서 '현장 대여'를 누른다 → S-05
2. 학생의 학번을 검색해 고르고, 장비 종류·기기 번호·반납일을 정한다
3. '대여 완료' → S2와 같이 '대여 중'이 된다

### S4. 반납받기 (근로학생)

1. S-04의 '대여 중' 탭에서 이름·학번·기기 번호로 검색한다
2. 대여를 누른다 → S-06. 장비 상태를 '정상' 또는 '문제 있음'으로 고르고, 문제가 있으면 메모를 적는다
3. '반납 완료' → 정상이면 다시 빌려줄 수 있고, 문제 있음이면 그 기기는 '수리 중'이 된다

### S5. 연체 확인하고 연락하기 (관리자)

1. PC에서 S-07을 열면 연체 중인 대여가 늦은 날 수 순서로 보인다
2. 학생 이름·연락처·기기·늦은 날 수를 보고 직접 연락한다
3. 학생이 반납하면(S4) 목록에서 사라진다

### S6. 대여 기록 찾기 (관리자)

1. S-08에서 기간·학생·장비 종류·기기 번호·상태로 걸러 지난 기록을 찾는다
2. 기록을 누르면 언제 누가 빌려주고 받았는지, 반납 상태와 메모를 본다

### S7. 장비 등록과 수리 처리 (관리자)

1. S-09에서 장비 종류를 추가하고 최대 대여 기간(일)을 정한다
2. 종류 안에 기기를 번호로 추가한다
3. '수리 중' 기기의 수리가 끝나면 '사용 가능'으로 되돌린다. 더 쓸 수 없는 기기는 '폐기'한다

## 화면 상세

### S-01. 장비 목록(홈) — 학생

- **보이는 것**:
  1. 맨 위 제목줄: 서비스 이름, 오른쪽에 내 대여 기록(S-03) 가는 버튼
  2. 연체 경고 (연체 중일 때만): "노트북-03 반납이 2일 늦었어요. 반납 전까지 새 예약을 할 수 없어요"
  3. 내 예약·대여 카드: 장비 종류·기기 번호, 받을 날 또는 반납일, 상태 칩(예약 / 대여 중 / 연체)
  4. 장비 종류 목록: 종류 이름, 오늘 남은 수량("3 / 10대"), 최대 대여 기간("최대 3일")
- **할 수 있는 것**:
  - 장비 종류를 누르면 S-02로 간다
  - 예약 카드의 '예약 취소' → 확인 팝업 → 취소. 카드가 사라지고 남은 수량이 하나 늘어난다
- **비어 있을 때**: 예약·대여가 없으면 카드 자리에 "빌린 장비가 없어요" 안내. 장비 종류가 하나도 없으면 "아직 빌릴 수 있는 장비가 없어요"
- **안 될 때**: 연체 중이면 장비 종류는 보이지만 누를 수 없다. 이미 같은 종류를 예약·대여 중이면 그 종류에 "대여 중" 표시, 누를 수 없다

### S-02. 예약하기 — 학생

- **보이는 것**:
  1. 제목줄: 뒤로 가기, 장비 종류 이름
  2. 장비 설명과 최대 대여 기간
  3. 달력: 받을 날 → 반납일 순서로 기간을 고른다. 주말·공휴일, 오늘부터 14일 뒤 이후, 남은 수량이 없는 날은 고를 수 없다
  4. 고른 기간 요약: "11.03 (월) 받기 → 11.05 (수) 반납, 3일"
  5. 휴대폰 번호 입력칸 (처음 예약할 때만): "연체 시 연락드려요"
  6. 맨 아래 고정 버튼 '예약하기'
- **할 수 있는 것**: '예약하기' → 확인 팝업(기간·장비 요약, "받는 날 창구가 닫을 때까지 오지 않으면 자동 취소돼요") → 완료 팝업 → S-01로 돌아간다
- **비어 있을 때**: 14일 안에 남은 수량이 있는 날이 없으면 "14일 안에 빌릴 수 있는 날이 없어요" 안내, 버튼 비활성
- **안 될 때**: 최대 기간보다 길게 고르면 반납일을 고를 수 없다. 휴대폰 번호 형식이 틀리면 입력칸 아래 오류 문구. 예약하는 사이 다른 사람이 마지막 수량을 가져가면 실패 팝업 "방금 다른 사람이 예약했어요. 다른 날을 골라주세요"

### S-03. 내 대여 기록 — 학생

- **보이는 것**: 제목줄(뒤로 가기, "내 대여 기록"), 지난 대여 목록 (장비 종류·기기 번호, 빌린 날 - 반납한 날, 상태 칩: 반납 / 자동 취소 / 취소. 반납일보다 늦게 반납했으면 '반납' 대신 '늦게 반납') 최근 순
- **할 수 있는 것**: 보기만 한다
- **비어 있을 때**: "아직 빌린 기록이 없어요"
- **안 될 때**: 없음

### S-04. 창구 홈 — 근로학생

- **보이는 것**:
  1. 제목줄: "창구", 오른쪽 '현장 대여' 버튼
  2. 탭: '오늘 받을 예약 (N)' / '대여 중 (N)'
  3. 검색창: 이름·학번 (대여 중 탭은 기기 번호도)
  4. 목록
     - 오늘 받을 예약: 학생 이름·학번, 장비 종류, 반납일
     - 대여 중: 학생 이름·학번, 기기 번호, 반납일, 연체면 연체 칩과 늦은 날 수. 오늘 반납일인 것과 연체가 위
- **할 수 있는 것**: 오늘 받을 예약을 누르면 S-05(예약 대여), 대여 중을 누르면 S-06, '현장 대여'를 누르면 S-05(현장 대여)
- **비어 있을 때**: "오늘 받을 예약이 없어요" / "대여 중인 장비가 없어요". 검색 결과가 없으면 "'홍길동'에 맞는 예약이 없어요"
- **안 될 때**: 근로학생 계정이 아니면 이 화면에 들어올 수 없다

### S-05. 대여 처리 — 근로학생

- **보이는 것**:
  - 예약 대여: 학생 이름·학번·휴대폰 번호, 장비 종류, 기간 (예약 그대로, 바꿀 수 없음)
  - 현장 대여: 학생 검색(이름·학번) → 장비 종류 고르기 → 반납일 고르기(오늘부터 최대 대여 기간까지, 평일만)
  - 공통: 빌려줄 수 있는 기기 번호 목록 ('사용 가능'인 기기만), 맨 아래 '대여 완료' 버튼
- **할 수 있는 것**: 기기 번호 하나를 고르고 '대여 완료' → 완료 팝업 → S-04로 돌아가고 그 대여는 '대여 중' 탭으로 옮겨진다
- **비어 있을 때**: 빌려줄 수 있는 기기가 없으면 "지금 빌려줄 수 있는 기기가 없어요" 안내, 버튼 비활성
- **안 될 때**: 현장 대여에서 그 학생이 연체 중이거나 같은 종류를 이미 빌리고 있으면 학생을 고를 때 이유와 함께 막는다. 고른 기간 중 남은 수량이 0인 날이 있으면(다른 학생의 예약 때문에) 그 반납일은 고를 수 없다

### S-06. 반납 처리 — 근로학생

- **보이는 것**: 학생 이름·학번, 기기 번호, 빌린 날·반납일(연체면 늦은 날 수), 장비 상태 선택('정상' / '문제 있음'), '문제 있음'이면 메모 입력칸(필수), 맨 아래 '반납 완료' 버튼
- **할 수 있는 것**: 상태를 고르고 '반납 완료' → 완료 팝업 → S-04로 돌아간다. '문제 있음'이면 그 기기는 '수리 중'이 된다
- **비어 있을 때**: 없음
- **안 될 때**: 상태를 고르지 않았거나, '문제 있음'인데 메모가 비어 있으면 버튼 비활성

### S-07. 연체 현황 — 관리자

- **보이는 것**: 왼쪽 메뉴(연체 현황 / 대여 기록 / 장비 관리), 연체 건수 요약, 연체 목록 표 (학생 이름·학번·휴대폰 번호, 장비 종류·기기 번호, 반납일, 늦은 날 수) 늦은 날 수가 많은 순
- **할 수 있는 것**: 보기만 하고 연락은 직접 한다
- **비어 있을 때**: "연체 중인 대여가 없어요"
- **안 될 때**: 관리자 계정이 아니면 들어올 수 없다

### S-08. 대여 기록 — 관리자

- **보이는 것**: 필터(기간, 장비 종류, 상태: 예약 / 대여 중 / 반납 / 연체 / 취소 / 자동 취소), 검색창(학생 이름·학번·기기 번호), 기록 표 (학생, 장비 종류·기기 번호, 빌린 날, 반납일, 반납한 날, 상태). 기록을 누르면 오른쪽에 상세 (빌려준 근로학생·받은 근로학생, 반납 상태와 메모)
- **할 수 있는 것**: 필터·검색, 기록 상세 보기
- **비어 있을 때**: "조건에 맞는 기록이 없어요"
- **안 될 때**: 관리자 계정이 아니면 들어올 수 없다

### S-09. 장비 관리 — 관리자

- **보이는 것**: 장비 종류 목록(이름, 최대 대여 기간, 전체 / 사용 가능 / 대여 중 / 수리 중 대수), 종류를 누르면 그 종류의 기기 목록(기기 번호, 상태 칩: 사용 가능 / 대여 중 / 수리 중 / 폐기, 수리 중이면 반납 메모)
- **할 수 있는 것**:
  - '장비 종류 추가' / 수정: 이름, 설명, 최대 대여 기간(일)
  - '기기 추가': 기기 번호
  - 수리 중 기기의 '수리 완료' → 사용 가능
  - '폐기' → 확인 팝업 → 폐기 (목록에서 흐리게 남고 더는 빌려줄 수 없음)
- **비어 있을 때**: "등록된 장비가 없어요. 장비 종류를 추가해주세요"
- **안 될 때**: 대여 중인 기기는 폐기할 수 없다. 같은 기기 번호는 두 번 추가할 수 없다

## 규칙

- **로그인**: 모두 학교 계정으로 로그인한다. 역할(학생 / 근로학생 / 관리자)에 따라 보이는 화면이 다르다
- **한 사람이 빌리는 개수**: 장비 종류마다 1개씩. 같은 종류를 예약·대여·연체 중이면 그 종류는 더 예약할 수 없다
- **예약 기간**: 받을 날은 오늘부터 14일 뒤까지. 받을 날부터 반납일까지는 그 장비 종류의 최대 대여 기간 이하
- **고를 수 있는 날**: 받을 날과 반납일은 창구를 여는 평일만. 주말과 공휴일은 고를 수 없다
- **남은 수량**: 그날 '사용 가능'인 기기 수에서 그날에 걸친 예약·대여 수를 뺀 것. 0이면 그날은 예약할 수 없다
- **자동 취소**: 받을 날 창구가 닫을 때까지 받아가지 않은 예약은 자동 취소된다
- **예약 취소**: 학생은 받기 전까지 언제든 취소할 수 있다
- **연체**: 반납일이 지나면 연체가 된다. 연체 중인 학생은 반납 전까지 어떤 장비도 새로 예약·대여할 수 없다. 반납하면 바로 다시 빌릴 수 있다
- **반납 상태**: '문제 있음'으로 반납하면 메모가 필수이고, 그 기기는 관리자가 수리 완료로 바꿀 때까지 빌려줄 수 없다
- **휴대폰 번호**: 처음 예약할 때 한 번 입력받아 기억한다. 관리자가 연체 연락에 쓴다
- **현장 대여**: 근로학생이 학생을 학번으로 찾아 바로 대여 중으로 기록한다. 개수 제한과 연체 규칙은 예약과 같다. 한 번도 로그인하지 않은 학생은 찾을 수 없으므로, 그 자리에서 학생이 폰으로 로그인하게 한다
- **공휴일**: 개발자가 미리 넣어둔다. 관리 화면은 없다

## 이번에 하지 않는 것

- 문자·카카오톡·푸시 알림 (반납일 알림, 연체 알림). 관리자가 연체 현황을 보고 직접 연락한다
- QR 코드로 대여·반납 처리. 근로학생이 목록에서 검색해 처리한다
- 연체한 날만큼 대여를 막는 벌칙. 반납하면 바로 다시 빌릴 수 있다
- 대여 기간 연장

## 열린 질문

- [ ] 창구가 닫는 시각 (자동 취소 기준, 예: 18:00). 반납일 당일 이 시각이 지나면 바로 연체인지, 다음 날부터 연체인지도 함께 — 관리자에게 확인
- [ ] 대여 기간을 세는 법. 화면 예시("11.03 받기 → 11.05 반납, 3일")는 받는 날과 반납일을 포함하고 주말도 센다고 가정한 것 — 관리자에게 확인
- [x] 공휴일 목록 → 개발자가 미리 넣어둔다. 휴교일 같은 임시 휴무도 개발자에게 요청한다 (관리 화면 없음)
- [x] 한 번도 로그인하지 않은 학생의 현장 대여 → 그 자리에서 학생이 폰으로 로그인한 뒤 학번으로 찾는다
- [x] 기기 폐기 기능 → 넣는다 (S-09)
- [ ] 학교 계정 로그인을 어떤 방식으로 붙일지 — 개발자가 서버 단계에서 정함
